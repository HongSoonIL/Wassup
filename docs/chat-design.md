# 모바일 채팅방 화면 설계

모바일에서는 대화방 한 개에 집중하고, 넓은 화면에서는 친구 목록과 열린 방을 나란히 둔다. 두 화면 모두 크림색 바탕과 라임색 강조를 사용한다.

| 대상 | 참고 화면에서 확인한 점 | wassup의 결정 |
|---|---|---|
| 캐릭터 상태 | Telegram은 대화 상대 이름 바로 아래에 마지막 접속 시각을 표시한다. | 도현 이름 근처에 현재 일과인 ‘카페 알바 중’을 표시해 답장이 늦어지는 이유를 대화 안에서 읽을 수 있게 한다. [Telegram 대화 화면](https://mobbin.com/flows/0ed23e0c-1de4-405f-acc7-50519575a487?tab=screens) |
| 입력창 | Telegram에서 전달할 메시지를 고르면 하단 입력 영역 오른쪽에 전송 동작이 나타난다. | 입력창과 전송 버튼을 대화 목록 아래에 둔다. 키보드가 열려도 방금 작성한 내용과 전송 버튼을 함께 확인할 수 있어야 한다. [Telegram 메시지 전달](https://mobbin.com/flows/0ed23e0c-1de4-405f-acc7-50519575a487?tab=screens) |
| 사진 | WhatsApp은 대화 안에서 사진을 작은 미리보기로 보여주고, 사진 상세 화면에서 크게 보여준다. | 일상 사진을 말풍선 크기로 보여준다. 사진을 누르면 큰 이미지로 열리고, 닫으면 같은 대화 위치에서 읽기를 이어간다. [WhatsApp 사진 상세](https://mobbin.com/flows/a3449050-518a-43da-a85b-636936623402?tab=screens) |
